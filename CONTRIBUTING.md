# Interested in collaborating?

Butterfly Effect Studio is currently under active development. The first priority is to make the editor reliable before releasing standalone games.

If you would like to help, email **hawktompa@gmail.com** with a short introduction, the area you are interested in (Python/PySide6, C++, game design, art, UX, testing), and whether you prefer feedback, small tasks or ongoing collaboration.

There is no public source-code contribution process yet. Please do not send copyrighted game art, third-party title screens, private credentials or confidential files.

The maintainer will decide when and how private development access or public contribution guidelines become available.
